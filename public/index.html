GET /productos Listar todos los productos

Retorna un array JSON con todos los productos registrados en memoria.

GET /productos/:id Consultar un producto por ID

Retorna el objeto JSON del producto correspondiente, o 404 Not Found.

POST /productos Crear un nuevo producto

Recibe { nombre, precio, stock, categoria, icono } en el body y retorna 201 Created.

PUT /productos/:id Actualizar un producto

Modifica los atributos del producto especificado por ID y retorna el objeto actualizado.

DELETE /productos/:id Eliminar producto por ID

Remueve el producto del arreglo en memoria y retorna mensaje de confirmación.
